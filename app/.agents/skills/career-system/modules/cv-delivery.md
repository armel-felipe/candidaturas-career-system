# cv-delivery

## Mandatory rules

- Gerar CV a partir do FIT_MAP e das evidências da candidatura, preservando idioma e contexto narrativo.
- O artefato final é DOCX em `outputs/`; revisar objetivamente o arquivo final antes de entrega.
- `cv:approve` é obrigatório antes de afirmar aprovação; `cv:deliver` é o caminho normal para entrega OneDrive quando configurado.
- Nunca substituir revisão do DOCX por inspeção do script gerador ou por texto exibido na conversa.
