> **Regra de uso:** Antes de escrever qualquer bullet, consultar este dicionário. Se o termo da vaga não estiver na Seção 1, ele não entra no CV.
>
> **Atualização:** Sempre que uma nova vaga for analisada e trouxer termos novos, adicionar aqui.

# SEÇÃO 2 — NÃO PODE USAR

> Termos que aparecem nas vagas mas **não têm evidência defensável na base**. Não entram em CV, carta ou narrativa.

| Termo da vaga | Por que não pode usar | O que dizer se perguntado |
|---|---|---|
| logística reversa (e-commerce) | Experiência limitada a B2B industrial (Trifil — recebimento, triagem, disposição). Sem operação de devolução de e-commerce | "Experiência com recebimento e triagem em contexto B2B industrial" |
| RPA (Robotic Process Automation) | WeHandle tinha IA e automação, mas RPA específico (robôs de processo tipo UiPath/Automation Anywhere) não está na base | Usar "automação de processos com IA" |
| NRR / GRR | VivaReal tem churn, mas NRR e GRR (Net/Gross Revenue Retention) não foram calculados ou nomeados assim | "Tenho churn como KPI — NRR/GRR não foi métrica formal no contexto" |
| cohorts | Análise de cohorts não aparece na base | Não usar |
| high-touch / tech-touch | Modelo de atendimento não foi nomeado assim | Usar "segmentação de carteira por perfil de cliente" |
| CMV / gestão de varejo físico | Sem experiência em varejo físico ou gestão de custo de mercadoria vendida | Gap real — não usar |
| gestão de contratos 3PL / transportadoras | iFood tinha parceiros logísticos, mas gestão formal de contrato com transportadora não está evidenciada | Usar "gestão de parceiros logísticos" |
| hubs físicos / CD próprio | iFood é last mile digital — sem gestão de hub físico ou CD próprio | Gap real — não usar |
| compliance fiscal / contábil / folha | Fora do perfil completamente | Gap real — não usar |
| CSC (Centro de Serviços Compartilhados) | Sem evidência de atuação em CSC | Gap real — não usar |
| espanhol (fluente) | Apenas básico — não usar como competência | Gap real — declarar básico se perguntado |

# SEÇÃO 4 — REGRAS DE USO

1. **Consultar antes de escrever** — nenhum termo entra no CV sem estar na Seção 1.
2. **Não inventar** — se o termo não está na Seção 1, verificar se há sinônimo na Seção 3. Se não houver, não usar.
3. **Frase pronta é ponto de partida** — adaptar ao contexto do bullet, não copiar literalmente.
4. **Número obrigatório** — todo bullet precisa de número defensável. Consultar Seção 15 do palavras_chave_carreira.md para validar.
5. **Atualizar após cada análise** — quando uma nova vaga trouxer termo novo, adicionar aqui com a evidência correspondente.
6. **Idioma do CV** — usar termo em inglês quando o CV for em inglês, português quando for PT. Seção 3 indica qual versão usar.
7. **autoconhecimento.md intocável** — este dicionário é uma camada de tradução. Nunca alterar a base de fatos original.
